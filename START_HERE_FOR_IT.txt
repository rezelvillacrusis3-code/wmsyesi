YESI GOOGLE SHEETS WMS — IT HANDOVER

This ZIP is for review. No installation or deployment has been performed.

1. Read README.md and docs/IT_SETUP.md.
2. Run npm.cmd run verify with Node.js 22 or newer.
3. Create a company-owned Apps Script project and set ADMIN_EMAIL and GATEWAY_SECRET.
4. Add Code.gs, Engine.gs and appsscript.json. Run setupWms to create the new Sheets structure and Drive folder.
5. Deploy the Apps Script gateway as the owner, accessible by Anyone. All data requests require the server's HMAC signature. Keep the URL and secret in Netlify server settings.
6. Create a Google OAuth web client for the Netlify origin.
7. Configure Netlify environment variables and build/deploy the project after approval.
8. Complete docs/ACCEPTANCE_TESTS.md with separate test data before loading company stock.

No production credentials are included. Do not place GATEWAY_SECRET in frontend files.
Do not import the automated test fixtures into live warehouse sheets.
